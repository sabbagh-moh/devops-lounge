AI for developers

  • Intro to Large Language Models: Karpathy's one-hour talk

    A single free talk that explains an LLM as an artifact (a big parameter file plus a small program that runs it), how training and fine-tuning produce one, and where the security problems come from. Start here if you use models daily but have never looked inside.

    LLMsBeginneryoutube.com

  • The Illustrated Transformer

    Jay Alammar's diagram-driven walkthrough of the architecture from the original transformer paper: self-attention, multi-head attention, positional encoding and the encoder and decoder stacks. Read it before the paper, then keep it open next to the paper.

    LLMsIntermediatejalammar.github.io

  • Attention Is All You Need, the original transformer paper

    The 2017 paper that introduced the transformer and dropped recurrence in favour of attention. Dense in places, but short, and nearly every modern language model descends from it. Pair it with the illustrated walkthrough.

    PapersAdvancedarxiv.org

Core developer skills

  • Git Mistake First Aid: Plain-English Recovery Recipes

    A short, no-jargon page of recipes for the Git situations that make people panic: committed to the wrong branch, a bad commit message, an undo that went too far. Bookmark it, then read the explanations so the fix stops feeling like magic.

    GitBeginnerdangitgit.com

  • Atlassian Git Tutorials: Workflows, Merging and Rewriting History

    Free, well-illustrated tutorials that go beyond commit and push: branching workflows, merge versus rebase, undoing changes and rewriting history. A good second Git resource once the basics are comfortable and you start working in a team.

    GitBeginneratlassian.com

  • Linux Journey: A Gentle Path From First Command to Confident User

    Free lessons in small chunks covering the command line, users and permissions, processes, networking and more. Start here if the terminal still feels foreign, and use the quizzes to check what actually stuck before moving on.

    LinuxBeginnerlinuxjourney.com

Open source worth reading

  • awesome: the list that defines the format

    awesome is the meta-list behind the whole awesome-list convention, and it is the place to start when you want a curated index of anything from languages to tooling. Read create-list.md first: it explains what separates a useful list from link spam, which is handy if you ever curate one yourself. Then browse readme.md by topic. License: CC0-1.0, so you can reuse the material freely.

    Awesome ListBeginnerWebgithub.com

  • awesome-selfhosted: services you can run yourself

    A long, well-sorted catalogue of free software you can host on your own machines, grouped by what it replaces: wikis, monitoring, chat, media, backups and much more. Useful for homelab ideas and for finding a mature project to read. Start with README.md for the categories; non-free.md keeps proprietary entries separate so the main list stays clean. License: CC-BY-SA-3.0 for the list content.

    Awesome ListBeginnerDevOpsgithub.com

  • awesome-go: the Go ecosystem, categorised

    If you write Go, this is the quickest way to find a library for routing, databases, CLIs, testing or concurrency without guessing. Entries are filtered for quality, so the list is shorter than a raw search. Fun extra: the repo ships its own Go code (main.go, pkg/, tmpl/) that builds the site, so you get a small real program to read too. License: MIT.

    Awesome ListBeginnerBackendgithub.com

Questions

What is DevOps Lounge?

DevOps Lounge is a free Discord community for developers and DevOps engineers at every level. Members ask questions, share projects, review code and find people to build with.

Is it free to join?

Yes. Joining is free and there is nothing to buy.

Is it for beginners?

Yes. There is a beginner track and a beginner corner, and every help forum welcomes first questions. Experienced engineers are there too, which is what makes the answers good.

What languages can I talk in?

English is shared by everyone, and there are rooms in Arabic, Spanish, Portuguese, French and Russian.

What topics does it cover?

Ten tracks: AI, web, app development, frontend, backend, mobile, data and ML, security, DevOps and cloud, and game development, plus career and interview help.

How do I get help with my code?

Post in the ask-a-question forum with what you tried and the error you see. When it is solved, the thread is tagged so others can find the answer later. There is also a code review channel.

Talk about it with other developers

It takes a minute: join, pick your language and what you work on, and say hi.
