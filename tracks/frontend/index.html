Start with these 16

  • awesome: the list that defines the format

    awesome is the meta-list behind the whole awesome-list convention, and it is the place to start when you want a curated index of anything from languages to tooling. Read create-list.md first: it explains what separates a useful list from link spam, which is handy if you ever curate one yourself. Then browse readme.md by topic. License: CC0-1.0, so you can reuse the material freely.

    github.comAwesome ListBeginner

  • create-t3-app: opinionated TypeScript web scaffolding

    A CLI that scaffolds a typed Next.js project, letting you opt into pieces like tRPC, Prisma or Drizzle and Tailwind. Reading cli/ shows how a good scaffolder composes templates and installers, which is a neat lesson on its own; www/ holds the documentation site. Use it when you want a well-trodden full-stack TypeScript layout. License: MIT.

    github.comStarterIntermediate

  • epic-stack: a full web app foundation with decisions explained

    A production-minded starter for a React Router app with Prisma, Playwright tests and Fly.io deployment config. What sets it apart is documentation of why choices were made: read docs/ and the decisions folder inside it before the code. Then explore app/, prisma/ and tests/ to see how it all fits. License: MIT.

    github.comStarterAdvanced

  • excalidraw: a whiteboard app and an embeddable library

    A real, widely used React app that is also published as a component. The editor lives in packages/excalidraw, the hosted app shell in excalidraw-app/, and dev-docs/ covers the internals and embedding. Study it for canvas rendering, state management and how a library is carved out of an app. License: MIT.

    github.comFull AppIntermediate

  • the-super-tiny-compiler: see a compiler in one file

    A heavily commented JavaScript file that compiles a toy Lisp-like syntax into C-like calls, walking through tokenising, parsing, transforming and code generation. Read the-super-tiny-compiler.js top to bottom and run test.js. Older and small, but still a clear introduction to compiler stages. License: CC BY 4.0.

    github.comLearningIntermediate

  • cal.diy: a scheduling app as a TypeScript monorepo

    A large Next.js scheduling application organised into apps/ (including web, api and docs) and shared packages/ such as prisma, trpc and emails. Useful for seeing how a real product splits concerns across a monorepo. Check the README for how this repository relates to the hosted product. License: MIT.

    github.comFull AppIntermediate

  • Next-js-Boilerplate: a tidy starter with tests

    A Next.js and TypeScript starter that bundles Tailwind, a database layer with Drizzle, linting, Vitest and Playwright. See src/ for the app, migrations/ for schema history and tests/ for how the checks are organised. Handy when you want a starting point with quality gates already in place. License: MIT.

    github.comStarterBeginner

  • prisma-examples: ready-to-run TypeScript data layer samples

    A collection of example projects that pair Prisma with different frameworks and databases. Browse orm/ for framework samples, databases/ for database-specific setups and deployment-platforms/ for hosting. Note the default branch is called latest. License: Apache-2.0.

    github.comTemplateBeginner
