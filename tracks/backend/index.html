Start with these

  • awesome-go: the Go ecosystem, categorised

    If you write Go, this is the quickest way to find a library for routing, databases, CLIs, testing or concurrency without guessing. Entries are filtered for quality, so the list is shorter than a raw search. Fun extra: the repo ships its own Go code (main.go, pkg/, tmpl/) that builds the site, so you get a small real program to read too. License: MIT.

    Awesome ListBeginnerBackendgithub.com

  • rustlings: small exercises that teach Rust

    Tiny broken programs you fix until they compile, each one introducing a Rust idea such as ownership, enums or traits. It runs in your terminal and checks your work as you save. Look in exercises/ for the tasks and solutions/ once you are stuck. A fast way to get over the borrow checker's first hurdles. License: MIT.

    LearningBeginnerBackendgithub.com

  • full-stack-fastapi-template: a deployable API and UI

    A complete starting point pairing a FastAPI backend with a React frontend, PostgreSQL and Docker Compose. It is useful as a reference for auth, migrations, tests and deployment wiring. Open backend/ and frontend/ for the code, compose.yml to see the stack, then development.md and deployment.md for the workflow. License: MIT.

    StarterIntermediateBackendgithub.com

  • awesome-rust: where Rust projects are indexed

    A broad index of Rust libraries, applications and resources, organised by domain from web frameworks to embedded and games. Handy for discovering mature crates before you write your own. Open README.md, and see CONTRIBUTING.md if you want to add something. The repo also contains a small Rust crate (Cargo.toml, src/) alongside the list. License: CC0-1.0.

    Awesome ListIntermediateBackendgithub.com

  • awesome-scalability: reading list for large-system design

    A reading list of engineering write-ups on scalability, availability and stability, grouped by topic and by company. Good for getting beyond textbook diagrams to how real systems failed and recovered. Work through README.md one section at a time and note the trade-offs each article makes. License: MIT.

    Awesome ListIntermediateBackendgithub.com

  • TheAlgorithms/Python: algorithms with readable implementations

    A large collection of algorithms and data structures written in plain Python for study. Folders such as dynamic_programming/, data_structures/, backtracking/ and ciphers/ make it easy to look up a topic, and DIRECTORY.md is the full index. Treat it as teaching code, not production code. License: MIT.

    LearningBeginnerBackendgithub.com

  • mal: write a Lisp interpreter in small steps

    A guided project to build a Lisp in numbered steps, with the same design implemented in dozens of languages under impls/. Start with process/guide.md, then compare your language's version with another you know. A rewarding way to learn parsing, evaluation, environments and tail calls. License: MPL-2.0.

    LearningAdvancedBackendgithub.com

  • cookiecutter-django: production defaults for Django

    A project generator that outputs a Django app with Docker, settings per environment, testing, and optional extras. Generate one, then read the template under {{cookiecutter.project_slug}} and the hooks/ that tailor the result. docs/ explains each option. License: BSD-3-Clause.

    StarterIntermediateBackendgithub.com

  • ardanlabs/service: a layered Go service starter

    A reference layout for production Go web services with Kubernetes in mind. The structure is explicit: app/ for entry points, business/ for domain logic, foundation/ for reusable pieces, and zarf/ for deployment config. Good reading on package design and project layering. License: Apache-2.0.

    StarterAdvancedBackendgithub.com

  • The Twelve-Factor App

    A short, influential guide to building services that are easy to deploy, configure and scale.

    GuideIntermediateBackend12factor.net

  • The Rust Programming Language

    The official Rust book, free online. A clear introduction to ownership and systems programming.

    BookIntermediateBackenddoc.rust-lang.org

  • SQLBolt

    Short interactive lessons that teach SQL by writing real queries in the browser.

    PracticeBeginnerBackendsqlbolt.com

  • A Tour of Go

    The official interactive introduction to Go. You run every example in the browser.

    PracticeBeginnerBackendgo.dev

  • FastAPI

    A modern Python web framework that uses type hints for validation and automatic API docs.

    FrameworkBackendfastapi.tiangolo.com

  • PostgreSQL

    A powerful open-source relational database and a safe default for most applications.

    ToolBackendpostgresql.org

  • Caddy

    A web server and reverse proxy that gets and renews HTTPS certificates automatically, with very little configuration.

    ToolBackendcaddyserver.com

  • Bruno

    An open-source API client that stores your collections as plain files, so they can live in Git with your code.

    ToolBackendusebruno.com

  • SQLite

    A small, reliable database stored in a single file, with no server required. It is often all a small project needs.

    LibraryBackendsqlite.org
