Start with these 11

  • awesome-ios: Swift and iOS libraries by topic

    A large index of iOS and Swift projects grouped by purpose: networking, architecture, UI components, testing, tooling and learning material. Good when you need to compare two or three options before adding a dependency. Open README.md and use the table of contents; the architecture and testing sections are the most useful for people past their first app. License: MIT.

    github.comAwesome ListBeginner

  • react-native-template-obytes: Expo app with good defaults

    A mobile starter built on Expo and TypeScript with Maestro end-to-end flows in .maestro/, EAS build config in eas.json, and an organised src/ folder. Worth reading for how it sets up env handling, linting, commit hooks and tests so a team can start with discipline. License: MIT.

    github.comStarterIntermediate

  • architecture-samples: Android app structure, compared

    Google's reference to-do app showing how to structure an Android project with Compose, Hilt and Room. The main code is in app/ and shared test helpers live in shared-test/, so you can study the layers and how tests are organised. Pair it with Now in Android once the basics are comfortable. License: Apache-2.0.

    github.comTemplateIntermediate

  • Now in Android: a full modern Android reference

    A working news app that Google uses to demonstrate current Android practice: modular layout, Compose UI, offline-first data and thorough testing. Look at core/ and feature/ to see the module split, build-logic/ for convention plugins, and docs/ for architecture notes. Heavy but very instructive. License: Apache-2.0.

    github.comFull AppAdvanced

  • awesome-android-ui: components worth studying

    A visual catalogue of Android UI libraries: animations, lists, dialogs, charts, transitions and more, with pointers to each repo. Useful when you want a polished interaction and would rather read an existing implementation. Everything is in README.md, and the art/ folder holds images. Check each library's maintenance before adopting. License: MIT.

    github.comAwesome ListBeginner

  • Signal-Android: study a security-minded messenger

    The Android client of a privacy-focused messenger, with a large modular Gradle layout (app/, lib/, core/) and a reproducible-builds/ folder explaining verifiable builds. Read it for encryption integration, background work and testing at scale. Heavy going, so pick one feature to trace. License: AGPL-3.0, which has strong copyleft terms.

    github.comFull AppAdvanced

  • flutter/samples: small apps for each Flutter feature

    The Flutter team's collection of samples, each in its own folder: animations/, form_app/, compass_app/ and more. Pick one that matches the feature you need and read its code. compass_app/ is the one to study for app architecture. License: BSD-3-Clause.

    github.comTemplateBeginner

  • Android Basics with Compose

    Google's free course for building Android apps with Kotlin and Jetpack Compose, with no experience needed.

    developer.android.comFree courseBeginner

  • The Swift Programming Language

    The official guide to Swift, free online. The language behind modern iOS development.

    docs.swift.orgBookBeginner

  • Flutter documentation

    Official docs and learning paths for building iOS, Android, web and desktop apps from one codebase.

    docs.flutter.devDocsBeginner

  • Flutter

    Google's open-source UI toolkit for building mobile, web and desktop apps from a single codebase.

    flutter.devFramework
