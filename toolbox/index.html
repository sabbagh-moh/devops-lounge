Tools developers keep

Command-line tools, frameworks and libraries that save time every week, from Kubernetes dashboards to infrastructure as code.

DevOps 12

  • OpenTofu

    An open-source, community-driven infrastructure-as-code tool that is a fork of Terraform.

    opentofu.orgCLI

  • Ansible

    Agentless automation for configuring servers and deploying software using readable YAML playbooks.

    docs.ansible.comTool

  • Prometheus

    A widely used open-source monitoring system and time-series database with its own query language.

    prometheus.ioTool

  • Grafana

    Open-source dashboards for your metrics, logs and traces from many data sources.

    grafana.comTool

  • k9s

    A terminal UI for managing Kubernetes clusters. It makes it much faster to inspect pods, read logs and jump between resources than typing kubectl commands.

    k9scli.ioCLI

  • ShellCheck

    A linter that finds bugs in shell scripts, such as unquoted variables. Try it in the browser or add it to your CI.

    shellcheck.netCLI

  • hadolint

    A Dockerfile linter that catches bad practices and checks the shell code inside your RUN instructions.

    github.comCLI

  • dive

    Explore each layer of a Docker image and find wasted space, so you can make your images smaller.

    github.comCLI

  • act

    Run your GitHub Actions workflows locally to test changes without pushing a commit every time.

    github.comCLI

  • Uptime Kuma

    A self-hosted monitoring tool with a clean dashboard, status pages and many notification options.

    github.comTool

  • tmux

    A terminal multiplexer. Split your terminal into panes and keep sessions running after you disconnect from a server.

    github.comCLI

  • Renovate

    Automates dependency updates by opening pull requests, so your projects do not silently fall behind.

    github.comTool

Backend 8

  • FastAPI

    A modern Python web framework that uses type hints for validation and automatic API docs.

    fastapi.tiangolo.comFramework

  • PostgreSQL

    A powerful open-source relational database and a safe default for most applications.

    postgresql.orgTool

  • Caddy

    A web server and reverse proxy that gets and renews HTTPS certificates automatically, with very little configuration.

    caddyserver.comTool

  • Bruno

    An open-source API client that stores your collections as plain files, so they can live in Git with your code.

    usebruno.comTool

  • SQLite

    A small, reliable database stored in a single file, with no server required. It is often all a small project needs.

    sqlite.orgLibrary

  • Hoppscotch

    A lightweight, open-source API testing tool that runs in your browser and can also be self-hosted.

    hoppscotch.ioTool

  • Valkey

    An open-source, high-performance key-value datastore, forked from Redis and backed by the Linux Foundation.

    valkey.ioTool

  • HTTPie

    A friendly command-line HTTP client with readable syntax and formatted output, made for working with APIs.

    github.comCLI

General 8

  • ripgrep

    An extremely fast tool for searching code that respects your .gitignore by default.

    github.comCLI

  • jq

    A small command-line tool for slicing, filtering and transforming JSON.

    jqlang.orgCLI

  • lazygit

    A simple terminal UI for Git. Staging single lines, rebasing and resolving conflicts all become much easier to see and do.

    github.comCLI

  • fzf

    A general-purpose fuzzy finder for the command line. Use it to search files, shell history, Git branches and anything else you can pipe into it.

    github.comCLI

  • pre-commit

    A framework for managing Git hooks, so linters and formatters run automatically before every commit.

    pre-commit.comTool

  • bat

    A cat replacement with syntax highlighting, line numbers and Git integration.

    github.comCLI

  • MkDocs

    Turn a folder of Markdown files into a clean documentation site, with very little setup.

    mkdocs.orgTool

  • Excalidraw

    A free, open-source whiteboard with a hand-drawn style. It is great for quick architecture diagrams.

    excalidraw.comTool

Security 5

  • Trivy

    An open-source scanner for vulnerabilities and misconfigurations in containers, code and infrastructure.

    trivy.devCLI

  • Gitleaks

    Finds passwords, API keys and tokens in your Git history. Run it as a pre-commit hook or in CI before a secret gets out.

    github.comCLI

  • Semgrep

    Fast static analysis for many languages, with rules that look like the code you are searching for.

    github.comCLI

  • ZAP

    A free, open-source web application security scanner. Only use it against applications you own or have permission to test.

    zaproxy.orgTool

  • Wireshark

    The classic network protocol analyzer. See exactly what is on the wire when something will not connect.

    wireshark.orgTool

Data/ML 3

  • scikit-learn

    The standard Python library for classic machine learning, with excellent documentation.

    scikit-learn.orgLibrary

  • Hugging Face Transformers

    An open-source library for using and training state-of-the-art machine learning models.

    github.comLibrary

  • DuckDB

    An in-process analytical database. Query CSV and Parquet files with SQL on your laptop, with no server to run.

    duckdb.orgTool

Frontend 2

  • Vite

    A fast frontend build tool and dev server with instant updates as you edit.

    vite.devTool

  • htmx

    A small library that adds dynamic behaviour with HTML attributes. Build interactive pages without a large frontend framework.

    htmx.orgLibrary

Web 1

  • Playwright

    Reliable end-to-end browser testing across Chromium, Firefox and WebKit.

    playwright.devLibrary

Mobile 1

  • Flutter

    Google's open-source UI toolkit for building mobile, web and desktop apps from a single codebase.

    flutter.devFramework

App 1

  • Tauri

    Build small, secure desktop and mobile apps with a web frontend and a Rust backend.

    tauri.appFramework

GameDev 1

  • Godot Engine

    A free and open-source 2D and 3D game engine with no royalties.

    godotengine.orgFramework
