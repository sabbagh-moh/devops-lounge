Free ways to learn to code

Free courses, books, docs and practice sites, sorted by area and marked by level, so you can start where you are.

General 9Web 5DevOps 4Backend 4Mobile 3Security 3Data/ML 2GameDev 2Frontend 1

General 9

  • CS50x

    Harvard's free introduction to computer science. A demanding and very well-taught foundation for any track.

    cs50.harvard.eduFree courseBeginner

  • The Missing Semester of Your CS Education

    MIT lectures on the tools most courses skip: the shell, editors, Git, debugging and more.

    missing.csail.mit.eduFree courseBeginner

  • Devhints

    A big collection of short, readable cheatsheets for languages, frameworks and command-line tools.

    devhints.ioCheatsheetBeginner

  • GitHub Git Cheat Sheet

    A one-page PDF of the Git commands you will use every day.

    education.github.comCheatsheetBeginner

  • roadmap.sh

    Community-built learning roadmaps and guides for almost every developer role.

    roadmap.shGuideBeginner

  • Pro Git

    The complete Git book, free to read online, from the basics to how Git works internally.

    git-scm.comBookBeginner

  • The Python Tutorial

    The official Python tutorial. A clear tour of the language for people who have programmed a little.

    docs.python.orgDocsBeginner

  • Learn Git Branching

    An interactive, visual way to learn branching and rebasing right in your browser.

    learngitbranching.js.orgPracticeBeginner

  • freeCodeCamp on YouTube

    Thousands of hours of free full-length programming courses on nearly every topic.

    youtube.comVideoBeginner

Web 5

  • freeCodeCamp

    A free interactive curriculum with projects and certifications, covering web development, Python, data and more.

    freecodecamp.orgFree courseBeginner

  • The Odin Project

    A free, project-based full-stack web curriculum that teaches you to use real tools from the start.

    theodinproject.comFree courseBeginner

  • Full Stack Open

    The University of Helsinki's free course on modern web development with React, Node.js and testing.

    fullstackopen.comFree courseIntermediate

  • MDN: Learn web development

    Mozilla's structured path through HTML, CSS and JavaScript, from one of the web's most trusted references.

    developer.mozilla.orgGuideBeginner

  • Eloquent JavaScript

    A well-loved book on JavaScript and programming in general, free to read online.

    eloquentjavascript.netBookBeginner

DevOps 4

  • tldr pages

    Community-written command-line help with practical examples, instead of long man pages.

    tldr.shCheatsheetBeginner

  • Site Reliability Engineering

    Google's book on running production systems, free to read online.

    sre.googleBookAdvanced

  • Docker: Get started

    The official hands-on introduction to containers, images and Compose.

    docs.docker.comDocsBeginner

  • Kubernetes Basics

    The official interactive tutorial for deploying, scaling and updating an app on Kubernetes.

    kubernetes.ioDocsIntermediate

Backend 4

  • The Twelve-Factor App

    A short, influential guide to building services that are easy to deploy, configure and scale.

    12factor.netGuideIntermediate

  • The Rust Programming Language

    The official Rust book, free online. A clear introduction to ownership and systems programming.

    doc.rust-lang.orgBookIntermediate

  • SQLBolt

    Short interactive lessons that teach SQL by writing real queries in the browser.

    sqlbolt.comPracticeBeginner

  • A Tour of Go

    The official interactive introduction to Go. You run every example in the browser.

    go.devPracticeBeginner

Mobile 3

  • Android Basics with Compose

    Google's free course for building Android apps with Kotlin and Jetpack Compose, with no experience needed.

    developer.android.comFree courseBeginner

  • The Swift Programming Language

    The official guide to Swift, free online. The language behind modern iOS development.

    docs.swift.orgBookBeginner

  • Flutter documentation

    Official docs and learning paths for building iOS, Android, web and desktop apps from one codebase.

    docs.flutter.devDocsBeginner

Security 3

  • OWASP Cheat Sheet Series

    Concise, practical guidance on specific application security topics such as authentication and input validation.

    cheatsheetseries.owasp.orgCheatsheetIntermediate

  • Web Security Academy

    Free, legal labs from PortSwigger that teach real web vulnerabilities and how to prevent them.

    portswigger.netPracticeIntermediate

  • OverTheWire Wargames

    Legal hacking games that teach Linux and security concepts. Start with Bandit.

    overthewire.orgPracticeBeginner

Data/ML 2

  • Practical Deep Learning for Coders

    fast.ai's free course teaches deep learning by building working models first and explaining the theory after.

    course.fast.aiFree courseIntermediate

  • Kaggle Learn

    Short, free, hands-on micro-courses on Python, pandas, SQL and machine learning that run in the browser.

    kaggle.comFree courseBeginner

GameDev 2

  • Learn OpenGL

    A free, thorough guide to modern graphics programming, from your first triangle to advanced lighting.

    learnopengl.comGuideAdvanced

  • Godot documentation

    Official docs for the free, open-source Godot engine, including step-by-step first game tutorials.

    docs.godotengine.orgDocsBeginner

Frontend 1

  • web.dev Learn

    Free courses from Chrome's developer relations team on CSS, performance, accessibility and more.

    web.devGuideIntermediate
