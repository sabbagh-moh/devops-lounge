Git command finder

Describe what you want to do in plain words, like "undo last commit" or "rename branch". Get the exact commands, what they do, and a warning when they rewrite history. 33 situations.

Undo the last commit but keep my changes 
git reset --soft HEAD~1

The commit is gone and its changes go back to staged, ready to commit again. Use HEAD~2 to undo two commits.

If you already pushed, prefer git revert so you do not rewrite shared history.

Removes the commit and every change in it from your working folder.

If you already pushed, use git revert HEAD instead.

Undo a commit that is already pushed

Creates a new commit that reverses the old one. History stays intact, which is safe for shared branches.

Questions

What is the difference between reset and revert?

reset moves your branch back and can drop commits; revert adds a new commit that undoes an old one. Use revert on anything already pushed.

What does --force-with-lease do?

It force-pushes only if nobody else pushed in the meantime, so you do not overwrite a teammate's work.
