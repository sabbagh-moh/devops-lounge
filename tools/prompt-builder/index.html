Prompt Builder

Describe what you want in your own words. It reads the request, asks what is missing, and writes a professional prompt for Claude, ChatGPT, Gemini, Cursor or Midjourney, built on the official prompting guides.

      How it works
      • It reads the requestIt tells a project from code, a bug, a review, a question or an image, and picks up the type of product, the references you name, the audience, the stack and the mood.
      • It asks what is missingAfter the first draft it asks only the questions that would change the result: the main job, the audience, the feel, the stack, the shot or the light. Every answer rewrites the prompt.
      • It writes like the guides sayRole, context, requirements, a plan-first process, acceptance criteria and a self-check, in XML for Claude, Markdown for ChatGPT and Gemini, or a task brief with verification for coding agents. Image prompts follow medium, subject, shot, light, lens and color, in the syntax of each model.
      
  
      Questions
      ?Is it an AI?
      It works like one, but it runs on rules and a knowledge base in your browser, so it is instant, free and private. Paste the prompt into any AI you like.
      ?Which assistants does it write for?
      Claude (XML sections), ChatGPT and Gemini (Markdown sections), Cursor or Claude Code (a task brief with acceptance criteria and verification), and for images Midjourney, ChatGPT images, Flux and Stable Diffusion.
      ?Why does it ask questions?
      Because the best prompts carry the details only you know: who it is for, what it must do and what done looks like. Answer the ones you care about and skip the rest.
      ?Is my idea sent anywhere?
      No. Everything happens on this page. Nothing is uploaded or stored.
