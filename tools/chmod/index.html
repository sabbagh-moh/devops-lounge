chmod calculator

Tick who can read, write and run a file. You get the number, the letters and the command to paste.

ReadWriteRun OwnerGroupEveryone else
Letters

How it works

  • Three digitsOne each for the owner, the group and everyone else. Read is 4, write is 2 and run is 1, added together.
  • Common picks644 for normal files, 755 for scripts and folders, 600 for SSH keys.

Questions

What does 777 do?

It lets anyone read, change and run the file. It is almost never what you want on a server.

Why does SSH refuse my key?

Private keys must not be readable by others. Run chmod 600 on the key file.
