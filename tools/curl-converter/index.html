cURL converter

Paste a cURL command from API docs or your browser's network tab. Get clean fetch, axios or Python requests code with headers, body and auth carried over.


  



  
cURL flags it understands
FlagMeaning
-X, --requestHTTP method, like POST or DELETE
-H, --headerA request header
-d, --data, --data-rawRequest body
--jsonJSON body, with JSON headers set
-u, --userBasic auth, turned into an Authorization header
-b, --cookieCookies
-G, --getSend the data as a query string
-A, --user-agentThe User-Agent header

  
How it works
  • Understands the usual flags-X, -H, -d and its variants, --json, -u for basic auth, -b for cookies, -G for query strings, and line breaks with backslashes.
  • JSON stays JSONA JSON body becomes a real object in the code, so you can edit it easily.

  
Questions
Where do I get a cURL command?
In Chrome or Edge, open the Network tab, right-click a request and choose Copy as cURL.
Are my tokens safe?
The command never leaves your browser. Still, replace real tokens before you share code.
