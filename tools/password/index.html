Passwords and UUIDs

Strong passwords and v4 UUIDs, made with your browser's secure random generator. Nothing is sent or saved.

Password

UUID v4

How it works

  • Real randomnessIt uses crypto.getRandomValues, the same source browsers use for encryption, with no bias between characters.
  • No look-alikesCharacters that are easy to confuse, like l, 1, O and 0, are left out.

Questions

How long should a password be?

At least 16 characters for accounts that matter, and use a password manager so you never retype it.

Are the UUIDs unique?

v4 UUIDs have 122 random bits, so a clash is practically impossible.
